# 評価ハーネスの読み方（指標の意味と「ものさしの検証」）

3条件（zero-shot / few-shot / LoRA）の出力を gold と比べて数値化するための道具。
実装は `metrics.py`、指標自体のテストは `validate_metrics.py`。

## なぜ指標が要るか

モデル比較を「なんとなく良さそう」でなく数値でやるため。ただし**ものさし自体が壊れて
いたら比較全体が無意味**なので、使い始める前に「ものさしのテスト」を行う（後述）。

## 各指標の意味

例: gold のノードが A「評価方法」B「グラフDBによる連想記憶」C「再現精度15%改善」、
モデル出力が a「評価の方法」b「グラフDBの連想記憶」d「頑張った点」だったとする。

### node F1（ノードがどれだけ合っているか）

ラベルは一字一句同じにならないため**曖昧マッチ**で対応付ける（文字バイグラム Jaccard:
2文字ずつの断片の重なり率。閾値以上なら同一概念とみなす。将来は埋め込み類似に差し替え可）。

- 上の例では a↔A・b↔B がマッチ、d は不一致。
- **precision** = マッチ数 ÷ モデルの出した数（= 2/3）→ 余計なものを出していないか
- **recall** = マッチ数 ÷ gold の数（= 2/3）→ 正解を取りこぼしていないか
- **F1** = 両者の調和平均。出しすぎも取りこぼしも罰する総合点（1.0 満点）

### typed F1（型まで合っているか）

マッチしたペアのうち **node_type も一致**するものだけ数えた F1。
「概念は拾えたが、型付け＝オントロジーの当てはめが正しいか」を分離して測る。
**転移仮説（型付けの流儀が未見ドメインに移るか）に最も直結する指標。**

### edge F1: strict / relaxed（関係が合っているか）

マッチしたノード同士で gold と同じ矢印があるか。
- **relaxed**: 矢印の存在だけ見る（種類は不問）
- **strict**: 矢印の種類（leads_to / causes …）まで一致

小さいグラフでは strict が過酷なため2本立て。「繋ぐ相手は合うが関係名だけ違う」を区別する。

### 粒度・一貫性系（gold が無くても測れる）

- **抽象ラベル率**: ラベルが「課題」「工夫」等のカテゴリ語そのものになっている割合（低いほど良い）
- **ノード数の平均・分散**: 粒度の安定性。LoRA で粒度が揃うなら**分散が縮む**はず
- **重複ノード率**: 同一グラフ内で類似ラベルが2つある割合（過細分化の検出）
- **孤立ノード率**: エッジが1本もないノードの割合
- **型付け一貫性**: 複数の出力を横断して、類似概念に同じ node_type を付けている率
  （＝暗黙オントロジーの一貫性。ドメイン跨ぎで測ると転移の直接証拠）

### 正規化と修復不能率（指標ではない）

出力形式は評価しない（後段の整形で吸収できるため）。パース不能な出力は決定論的修復を
試み、それでも駄目なら**修復不能率**としてだけ報告（黙って捨てると、壊れた出力を量産する
モデルほど「パースできた良い出力だけ」で評価される生存者バイアスが生じる）。

## ものさしの検証（指標のユニットテスト）

> **gold をわざと特定のやり方で壊し、「対応する指標だけ」が下がることを確認する。**

塩分計のテストに例えると、スープに塩だけ足して「塩分計だけ上がり、温度計は動かない」
ことを見るのと同じ。実行: `python3 eval/validate_metrics.py ../gold-editor/gold/gold.jsonl`

gold 9件での結果（2026-07）:

| 壊し方 | 期待 | 実際 | 判定 |
|---|---|---|---|
| self（無傷） | 全指標 1.0 | 全て 1.0 | ✅ |
| C1 型シャッフル | typed だけ落ちる | typedF1 1.0→0.198、node/edge は 1.0 のまま | ✅ |
| C2 抽象ラベル置換40% | nodeF1 低下・抽象率上昇 | nodeF1 0.626、抽象率 0→0.374 | ✅ |
| C3 ノード過分割 | precision 低下・ノード数増 | F1 0.68、ノード数 13.7→26.6 | ✅ |
| C4 関係シャッフル | strict だけ落ちる | strict 0.537、relaxed 1.0 のまま | ✅ |

**「落ちるべきものが落ち、落ちるべきでないものが動かない」**＝指標が互いに独立に
働いていることを確認済み。以後のモデル比較の数字は信頼してよい。
